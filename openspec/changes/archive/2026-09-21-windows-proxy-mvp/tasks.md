## 1. M0 技术验证门槛（阻塞网络实现）

- [x] 1.1 建立 Windows 10/11 x64 验证环境与受控 SOCKS5/HTTP/SSH 测试端点；交付环境、版本和可重复连通性记录，不使用真实秘密作为测试数据。证据：`docs/validation/environment.md`、`docs/validation/m0-windows11.md`。
- [x] 1.2 选定 sing-box 版本并核对 TUN、配置校验、出站选择、DNS 和日志接口；以最小配置校验及启动结果记录支持矩阵和锁定版本。
- [x] 1.3 验证受管理 DNS/FakeIP 对浏览器和 SSH 域名连接的支持；用代理端/目标端观测覆盖 IPv4、IPv6、缓存及应用 DoH 的预期边界，以及域名访问命中真实 IP/CIDR/范围、多地址任一命中、混合内网候选和解析失败场景。
- [x] 1.4 验证 SOCKS5/HTTP 无认证、有认证、错误密码和 HTTP CONNECT 22 被拒；记录 UDP 支持情况以及无静默直连的端点证据。
- [x] 1.5 验证 MVP 异常恢复边界；终止内核及宿主进程，记录实际网络状态、可能直连提示、显式直连和下次启动恢复结果，不以系统级阻断作为通过条件。证据：`docs/validation/windows-runtime-failure.md`、`docs/validation/evidence/windows11-host-crash-results.json`。
- [x] 1.6 验证提升后的账户身份、用户范围凭据读写和临时文件 ACL；标准用户使用管理员凭据启动时须有明确数据归属记录。
- [x] 1.7 验证实际连接日志能否关联目标、出站和命中规则；交付真实事件样本及无法获取字段的明确边界。证据：docs/validation/m0-windows11.md 及 evidence 中的 TUN/认证失败日志。
- [x] 1.8 核对内核与 TUN 依赖分发条件；交付版本、来源、校验和与许可证清单，任何无法满足规格的实验须先修订提案。
- [x] 1.9 验证 FakeIP 持久映射和缓存恢复；以兼容重启保留映射、映射损坏拒绝旧地址、直连后系统重新解析及应用私有缓存提示为验收证据。证据：`docs/validation/strict-cache-patch.md`、`docs/validation/windows-network-recovery.md`。
- [x] 1.10 验证独立直连 DNS 和代理目标解析路径；在代理不可达时验证未命中域名可访问，另测直连 DNS 故障及命中域名代理解析失败无直连回退。

- [x] 1.11 实现并交付严格缓存模式补丁及可重复构建脚本；验证默认模式兼容、严格模式首次创建/健康重启、空/损坏缓存不改写、运行期异常退出并保留缓存，保存本地与 Windows 测试证据。
- [x] 1.12 在 Windows 对补丁构建重跑代理认证、SSH/UDP、DNS、TUN、FakeIP 映射及资源清理回归；记录版本、校验和与对应源码包。
