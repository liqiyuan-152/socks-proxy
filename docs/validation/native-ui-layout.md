# 原生桌面布局与五页导航

日期：2026-09-21。实现：Rust `eframe/egui 0.36.2`，不使用 HTML、CSS、JavaScript 或 WebView。

主窗口采用约 164 px 常规导航、右侧工作区和 34 px 底部状态条。固定五页为状态、代理、分流规则、连接日志、设置；状态条跨页面保留当前模式、网络恢复状态和内核运行状态。默认窗口为 1000×680，最小 760×520；窄窗口将导航收为带工具提示的图标栏。

`design-reference-20260921` 中的八张页面切分图是当前视觉基准。本实现以原生控件落实浅色 Windows 工具风格：模式使用分段选择，状态页使用双栏运行摘要，代理和规则页使用左侧列表加右侧详情，日志使用筛选工具栏和可展开详情，设置按启动、备份和网络恢复分组。页面不使用渐变或营销式大标题。

本机实际渲染检查发现并修复两项问题：egui 默认字体缺少中文字符，以及深色全局视觉与浅色面板混用造成的低对比度。当前按平台加载 Windows 微软雅黑、macOS 苹方或 Linux Noto CJK，并统一使用浅色视觉。

本机实际渲染检查结果：

- 状态页的三模式选择、双栏代理与内核摘要、最近错误和连接摘要无重叠；重复 Grid ID 调试提示已修复。
- 代理与规则页的低优先字段进入右侧详情，避免固定列永久截断；规则筛选不改变底层顺序。
- 日志支持目标/规则、出站和结果组合筛选，详情保留脱敏长文本，并提供复制入口。
- 五页均可从同一左侧导航到达，选中态清晰；底部状态条保持固定高度。
- 主窗口关闭请求转换为隐藏窗口，为后续单一托盘生命周期保留进程。

本机 `cargo test --locked` 已通过 72 个单元测试和 16 个集成测试。Windows 10/11 的 100%/150% DPI、最小窗口、键盘焦点及新版截图尚待重新实机验收，旧版截图与检查结果不能证明本次改版。
