## 1. 切换状态与诊断基线

- [ ] 1.1 在运行时/事务边界定义可关联的模式切换阶段、结果和脱敏耗时事件，并用单元测试验证成功、预检失败、启动失败与回滚事件顺序和不含凭据。
- [ ] 1.2 为桌面控制器增加单一后台模式切换作业及不可阻塞的快照读取接口，验证重复模式、代理、规则和退出请求在作业期间被禁用或明确拒绝。
- [ ] 1.3 将主窗口和托盘接入进行中阶段、最终结果及实际 `applied_mode`，验证等待就绪时窗口仍可移动、最小化、切换到日志页并读取状态。

## 2. 无中断预检与受控重启

- [ ] 2.1 抽取非直连目标的可复用预检产物，完成凭据读取、上游解析、配置编译、受限写入和内核校验，并用测试验证预检失败不会停止当前有效内核或改变已应用模式。
- [ ] 2.2 让启动阶段消费预检产物，保持现有成功提交、持久化和失败回滚语义；运行 `cargo test --locked` 验证配置、事务和控制器覆盖通过。
- [ ] 2.3 为预检临时文件和失败路径实现受限清理与启动残留处理，验证文件权限、错误日志和诊断输出均不含明文凭据。

## 3. TUN 生命周期与恢复边界

- [ ] 3.1 将规则代理与全局代理的过渡改为复用本程序拥有的 TUN 适配器，并用短间隔、有上限的进程/设备状态轮询替换固定 500ms 等待；用确定性后端测试验证正常、延迟释放和超时路径。
- [ ] 3.2 保留全局直连、退出、异常恢复及 TUN 复用失败时的完整适配器删除、路由/DNS 恢复和 DNS 缓存刷新，验证 DNS 刷新失败不会虚报恢复成功且可重试。
- [ ] 3.3 预留默认关闭的 sing-box 热重载能力边界与实际路径诊断，不启用实现；验证未启用时始终回退至受控重启。
