# Socks Proxy 使用与恢复说明

## 安装与启动

支持 Windows 10/11 x64。运行安装包后从开始菜单打开 **Socks Proxy**。程序每次启动请求管理员权限；取消授权时不会启动内核或修改网络。首次启动默认选择规则代理；尚未配置当前代理时不会启动内核或修改网络，并提示先完成代理配置。默认不开机启动。

关闭主窗口只会隐藏到系统托盘。左键托盘图标显示或隐藏窗口；右键可切换模式、当前代理、页面或退出。只有托盘“退出”才结束程序并恢复网络。退出会立即显示“正在退出”，后台完成内核、TUN 和 DNS 清理后才关闭；清理失败或超时时窗口保留并显示错误，可再次尝试退出。

## 桌面界面

窗口左侧提供“状态、代理、分流规则、连接日志、设置”五个页面。常规窗口显示图标和文字；窗口缩小到最小支持尺寸时导航收窄为图标栏，悬停图标可查看页面名称。底部状态区持续显示当前模式、网络接管提示和实际内核阶段。

“状态”页可直接切换规则代理、全局代理和全局直连；切换过程中会显示“正在应用配置”，相关切换控件暂时不可用。页面同时显示当前代理、DNS、配置修订、最近错误和最近连接摘要。

“代理”和“分流规则”页面均采用左侧列表、右侧详情的布局。选择列表项后，可以从详情区编辑、设为当前代理、启用或停用规则，或删除项目。规则页的筛选框匹配名称、目标和备注，不会修改规则内容或顺序。

“连接日志”可按目标或规则文本、实际出站和成功/失败组合筛选。选择“详情”可查看完整脱敏字段；详情中的目标、规则、结果和错误文本可选择或复制。清空日志会关闭当前展开的详情。

## 代理与模式

在“代理管理”添加 SOCKS5 或 HTTP 代理并选中一个当前代理。认证密码由当前 Windows 账户的 DPAPI 保护，不写入普通配置、备份或日志。导入备份后，带认证的代理需要重新填写凭据。

- **规则代理**：启用的规则按目标与端口匹配，规则内条件为 AND，规则间为 OR；未命中流量直连。
- **全局代理**：公网流量使用当前代理，本机、链路本地和纯内网目标直连。
- **全局直连**：停止 TUN 和内核并恢复本程序接管的网络状态。

切换代理模式会在需要时自动重启内核，不再要求二次确认；现有 SSH 或其他长连接可能中断，只保证新连接使用新路径。切换当前代理或修改正在使用的配置仍会在需要重启时请求确认。

## DNS、HTTP 与 UDP 边界

程序使用受管理 DNS 和 FakeIP 恢复域名并支持真实 IP、CIDR 和范围规则。启动解析、代理服务器解析、未命中域名及 IP 规则判定使用独立直连 DNS，因此这些查询可能暴露给本地 DNS。应用自带 DoH/DoT 或私有 DNS 缓存可能绕过域名恢复；此时只能按可见 IP 和端口判断。

域名规则命中后优先由代理侧解析。代理不可达、认证失败、代理侧解析失败或协议不支持时，匹配连接失败，不静默回退直连。HTTP 代理是否允许 CONNECT 到 22 端口取决于服务器；HTTP 出站不支持普通 UDP。SOCKS5 UDP 只在上游支持时可用，首版不承诺游戏或全部 UDP 场景。

## 故障与日志

内核退出后状态和托盘图标变为异常，已应用模式被清除，但最后成功模式保留。此时系统级阻断不可用，流量可能直连。可重新启用最后成功模式，或显式选择全局直连完成恢复。

连接日志只记录目标、出站、结果及内核可验证的规则标识，不记录通信正文。无法从内核取得规则证据时显示“未知”。日志在写盘及展示前脱敏，最多保留 7 天和 20 MiB，可随时清空；列表中的“详情”可查看完整脱敏目标、端口、出站、规则、结果和错误文本。

## 离线恢复

当界面仍可用时，先选择“全局直连”，确认状态栏显示直连，再从托盘退出。如果界面无法使用：

1. 以管理员身份打开 PowerShell。
2. 结束残留进程：`taskkill /F /IM socks-proxy.exe` 和 `taskkill /F /IM sing-box.exe`。
3. 运行安装目录中的 `socks-proxy.exe --recover-direct`。
4. 检查不存在名为 `socks-proxy` 的网络适配器：`Get-NetAdapter -Name socks-proxy -ErrorAction SilentlyContinue` 应无输出。
5. 刷新系统 DNS：`Clear-DnsClientCache`。浏览器、SSH 客户端等仍使用旧 FakeIP 时，关闭并重新打开对应应用。

恢复命令只清理本程序拥有的状态，不覆盖 VPN 或其他网络工具后续写入的设置。若恢复命令失败，保留 `%LOCALAPPDATA%\SocksProxy` 以便诊断，重启 Windows 后再次执行；不要在网络尚未恢复时删除该目录。

卸载程序会结束应用、调用同一恢复入口并删除程序文件。用户配置位于 `%LOCALAPPDATA%\SocksProxy`，卸载默认保留，便于升级及故障诊断。
