## 被后续决定替代的建议

- Tauri/Web 界面已被非 Web 要求替代。
- 每条规则选择不同代理、任意直连/阻止动作不纳入首版；规则只决定是否走统一当前代理。
- 独立“开启代理”开关被三种模式取代；没有第四种“规则直连”。
- 较早“默认规则代理”被后续接受的“首次直连、以后恢复”替代。
- 常驻后台服务不纳入首版。

## 本次规划采用的工程默认值（不是原话确认）

这些是提案设计选择，可在实施前调整，不应冒充已实现或用户逐项确认：

- 稳定 ID、版本化 JSON、导入预览后仅在已恢复的直连状态整体替换且失败原子回滚；首版仅提供无密码导出，保留认证启用标记。
- 只恢复最后成功应用模式；删除当前运行代理前要求先切换或进入直连。
- 日志默认 20 MiB / 7 天，按先触达阈值清理。
- 域名规则以受管理 DNS 路径为可靠保证，自有 DoH/缓存无法关联时明确限制。
- TCP 为必须验收范围；HTTP 不支持的 UDP 失败，SOCKS5 UDP 按能力启用。
- 审查修订：撤销将系统级崩溃阻断列为 MVP 硬要求的扩展；内核正常运行时禁止上游故障直连 fallback，内核崩溃及恢复期间明确提示可能直连。系统级保护作为后续独立增强提案候选，尚未单独立项。
