# 原生桌面布局与五页导航

日期：2026-09-20。实现：Rust `eframe/egui 0.36.2`，不使用 HTML、CSS、JavaScript 或 WebView。

主窗口采用 176 px 左侧导航、右侧工作区和 34 px 底部状态条。固定五页为状态、代理、分流规则、连接日志、设置；状态条跨页面保留当前模式、网络恢复状态和内核运行状态。窗口默认 920×620，最小 760×520。

原始需求会话中的网页草图只用于确认五页信息架构，没有被视为批准的视觉设计。本实现重新以原生控件落实：模式使用分段选择，代理使用下拉选择，代理/规则/日志使用紧凑表格，开机启动使用复选框，命令使用普通按钮。页面不使用嵌套卡片或营销式大标题。

本机实际渲染检查发现并修复两项问题：egui 默认字体缺少中文字符，以及深色全局视觉与浅色面板混用造成的低对比度。当前按平台加载 Windows 微软雅黑、macOS 苹方或 Linux Noto CJK，并统一使用浅色视觉。

逐页检查结果：

- 状态页的三模式选择、当前代理和状态明细无重叠。
- 代理表的长服务器地址在固定列内截断，不挤压认证和状态列。
- 规则、日志及设置页均可从同一左侧导航到达，选中态清晰。
- 920×620 和最小 760×520 均无文本遮挡；底部状态条保持固定高度。
- 主窗口关闭请求转换为隐藏窗口，为后续单一托盘生命周期保留进程。

74 个 Rust 测试、Clippy `-D warnings` 和 Windows MSVC 全目标交叉检查通过。首页和代理管理已在 5.2 接入真实共享控制器；规则编辑、托盘和设置行为分别由 5.3–5.5 接入。
