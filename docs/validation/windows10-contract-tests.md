# Windows 10 配置与规则契约验证

验证日期：2026-09-21。平台：Windows 10 Pro 10.0.19045 x64 Hyper-V VM。Rust 测试以 `x86_64-pc-windows-msvc` 编译并在 VM 内直接执行，不使用 macOS 运行结果代替。

五个测试二进制全部通过：库测试 57 项、网络 4 项、代理 5 项、路由 5 项、规则 2 项，共 73 项。覆盖版本化配置恢复、导入状态与失败回滚、不可变凭据事务、日志脱敏和保留限制、代理 CRUD 与单选约束、五类规则、域名标签边界、IPv4/IPv6/CIDR/IP 范围、端口解析、禁用规则、三种模式和上游防回环顺序。

另以真实 `1.14.1-socks-proxy.2` 内核执行 `windows_core_config_smoke.exe`。生成的认证 SOCKS5 配置通过内核 `check`；用户名和密码未进入命令行；临时配置 ACL 只允许当前用户和 SYSTEM；释放后文件被删除。该结果只证明配置编译、秘密隔离与 ACL，不替代真实上游认证连接。

机器可读结果和各二进制 SHA-256 见 `evidence/windows10-rust-tests.json`。需要桌面点击、跨账户 DPAPI、真实 SSH 长连接或物理网卡转换的场景不由这些测试判定完成。
