## Purpose

为用户提供多个 SOCKS5 和 HTTP 代理配置的统一管理能力，明确当前代理的单选约束、可选认证及校验失败反馈，让所有分流规则使用同一个已选代理。

## Requirements

### Requirement: 管理代理配置

程序 SHALL 支持新增、编辑和删除 SOCKS5 / HTTP 配置，包含稳定标识、名称、服务器地址、端口及可选用户名和密码；凭据不得回显明文。

#### Scenario: 无认证代理
- **WHEN** 保存地址合法、端口为 1080 且不含凭据的 SOCKS5 配置
- **THEN** 保存成功，不要求填写认证信息。

#### Scenario: 认证代理
- **WHEN** 保存提供用户名和密码的 HTTP 配置
- **THEN** 后续连接使用该配置的认证信息，列表不展示密码。

#### Scenario: 非法输入
- **WHEN** 提交空地址、非法地址或不在 1–65535 内的端口
- **THEN** 阻止保存并定位错误，不覆盖已有配置。

### Requirement: 单个当前代理

程序 SHALL 允许保存多个代理但仅有一个当前代理；规则不得单独选择不同代理。切换失败 SHALL 保留旧的有效状态。

#### Scenario: 统一切换
- **WHEN** 将当前代理由 A 切换到 B 并应用成功
- **THEN** 后续应代理的新连接统一使用 B，规则内容保持不变。

#### Scenario: 缺少代理
- **WHEN** 没有有效当前代理时请求进入规则代理或全局代理
- **THEN** 拒绝启用并提示先配置代理，不显示已启用。

#### Scenario: 删除当前代理
- **WHEN** 用户删除当前正在承载代理流量的配置
- **THEN** 要求先切换其他代理或显式进入全局直连，不静默直连。

### Requirement: 代理协议失败反馈

程序 SHALL 显示认证、连接和 HTTP CONNECT 被拒绝等失败，且不得为这些连接自动回退直连。

#### Scenario: SSH 被 HTTP 代理拒绝
- **WHEN** 当前 HTTP 代理拒绝到目标 22 端口的 CONNECT
- **THEN** 连接失败，显示可诊断原因；不能因服务端限制宣称 SSH 已连接。
